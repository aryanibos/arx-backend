# Contributing

Contributions are welcome.

## Rules

- Keep the skill project-agnostic.
- Do not weaken the rule that project-specific architecture takes precedence.
- Do not add secrets or credential examples.
- Keep changes focused and reviewable.
- Update the plugin version for published behavioral changes.

## Pull requests

Explain:
- what changed
- why it improves backend implementation/review behavior
- whether the change is backward-compatible
- any new reference files or rules
